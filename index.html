Slot Antenna Modeler

Design a wire-grid slot antenna and export an EZNEC "First Format Type" wire coordinate file.

Units & Frequency

 

Substrate

 

Length runs along the grid's horizontal (columns), width along vertical (rows).

Grow/shrink substrate live, without a rebuild -- solid arrow = add (points outward); hollow arrow = remove (points inward). Sized to the base max cell size below.

Upper bound on grid-edge length. Columns/rows are sized to fit the substrate exactly, at or under this value.

Default is cell-size / π (EZNEC manual's equal-surface-area rule for wire-grid modeling of a solid sheet); edit freely. Doesn't auto-follow cell-size changes -- use the button to resync.

A real feed conductor is thin, not the (deliberately thick) mesh wire -- kept separate. Default is a representative hookup-wire gauge; edit freely.

Rebuilding regenerates rows/columns and clears any refinement/cell edits made so far -- click Undo right after if that was accidental.

Slot guidance

 

Feed point

Click two nodes across the slot to insert a feed wire between them. It's exported as a real 1-segment wire; add the EZNEC source at 50% (its center) — that's the point marked in red. Use "Clear feed" in the toolbar to remove it.

None marked — use the Feed tool and click two grid nodes.
